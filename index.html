      How the two lists are built

      User-Based

      1. Compare the active user's rating vector with every other user using cosine similarity over co-rated movies only.
      2. Keep the 20 most similar users (positive similarity, at least 5 co-rated movies).
      3. For every unseen movie, predict a score as the similarity-weighted average of those neighbours' ratings.
      4. Rank by predicted score and show the Top-5.

      Item-Based

      1. Compare every movie's rating column with every other movie's column using the same cosine similarity function.
      2. For a movie the user has not seen, aggregate the similarities from the movies they did rate, weighted by the rating they gave.
      3. Rank by the aggregated score and show the Top-5.

      Missing values: the rating matrix is 93.7% empty, so every similarity is computed over co-rated items only — a movie one user has not seen is simply skipped rather than treated as a zero. This single strategy is used consistently everywhere.
